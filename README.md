# Task-2
Super Store Sales Dashboard.

I performed data cleaning of SuperStore Dataset I obtained from Kaggle.com using Power BI. Shortly after cleaning using transformation feature I close and apply 
I created Measures for easy calculation and data visualization
I created Dimension for easy usage of date
In the visual I used card to illustrate Total Orders, Total Sales, Total Profit and Profit Margin for the period in view
I used Cluster Bar Chart to show Category and region that bought sold most. 
I used Line Chart to show sales trend over time. In this I used drill through feature that will enable user to check how sales perform Month on Month and Year on Year.
I used Stark Bar Chart to generate Top 5 customers. I used filter feature to get the required number (Top N)
I created Year, Region and Category Slicers to show the dashboard is interactive.
